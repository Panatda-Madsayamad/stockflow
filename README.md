# StockFlow

A lightweight inventory management REST API built with
TypeScript, Fastify, SQLite, and Drizzle ORM.

## Features

- Create and view inventory items
- Update item details
- Search items by name or SKU
- Receive stock and issue stock
- Track inventory movement history
- Validate request data
- Reject stock issues when inventory is insufficient
- Use database transactions to update stock and record movements

## Tech Stack

- Node.js
- TypeScript
- Fastify
- SQLite
- Drizzle ORM
- better-sqlite3
- Git and GitHub
